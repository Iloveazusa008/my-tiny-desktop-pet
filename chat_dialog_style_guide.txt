任务：改造 src/chat_dialog.py 的对话框外观。

现状：对话框是 Windows 原生灰色风格，原因是带系统窗口装饰，
颜色无法在代码里控制。

目标：改成白底、紫边、圆角、右上角带小叉的自绘对话框。

做法：去掉系统装饰（FramelessWindowHint + WA_TranslucentBackground），
用「外层透明 + 内层白底紫边」两层结构，QSS 设置白底紫边圆角，
QGraphicsDropShadowEffect 加阴影，右上角放一个自绘小叉。

代价：去掉系统装饰后，窗口拖动、阴影、关闭按钮都要自己补，
但现有的关闭逻辑、信号、记忆清空、落位、raise 一律保持不变。

约束：只改 src/chat_dialog.py，不引入第三方 UI 库，
不改动 pet_window.py 中无关逻辑，完成后同步 progress.md。

验收：白底紫边圆角带阴影、小叉可关、三种关闭方式行为一致、
输入框内选字窗口不乱跑。

详细要求见下文各节。

ChatDialog 视觉改造参考文件
适用文件：src/chat_dialog.py
目标：将原生灰色对话框改为白底紫边、圆角、右上角小叉的自绘对话框
========================================================


────────────────────────────────────────
零、背景与问题根因
────────────────────────────────────────

当前对话框使用 Qt 默认窗口，带系统原生装饰：
- 标题栏
- 边框
- 关闭按钮
以上全部由 Windows 绘制，颜色、字体、圆角均无法在代码中控制，
因此无论怎么设置样式，外观仍是系统底层灰色风格。

要让对话框变成白底紫边，必须去掉系统装饰，自己接管窗口外观。


────────────────────────────────────────
一、总方向
────────────────────────────────────────

1. 去掉系统原生窗口装饰。
2. 自行绘制标题区、边框、关闭按钮。
3. 保留全部现有交互逻辑（关闭方式、信号、记忆清空、落位、raise）。
4. 不引入第三方 UI 库。
5. 改动集中在 src/chat_dialog.py，不改动 pet_window.py 中无关逻辑。


────────────────────────────────────────
二、窗口标志与属性
────────────────────────────────────────

需要在 ChatDialog 上设置：

- Qt.FramelessWindowHint
  作用：去掉系统标题栏与边框。

- Qt.WA_TranslucentBackground
  作用：支持圆角与阴影，否则圆角外会出现黑角。

注意：
- 不要再额外设置 Qt.WindowDoesNotAcceptFocus。
  该标志会导致「点外部关闭」（WindowDeactivate）失效。
- Esc 关闭、点外部关闭依赖现有 event() 拦截逻辑，保持不动。


────────────────────────────────────────
三、推荐结构
────────────────────────────────────────

采用「外层透明 + 内层白底紫边」两层结构：

QDialog（无边框 + 透明背景）
└── 外层容器（负责给阴影留空间）
    └── 内层容器（负责视觉样式）
        ├── 顶部行：标题 + 右上角小叉
        ├── 只读日志区
        └── 输入行：输入框 + 发送按钮

说明：
- 外层通过布局 margin 留白，让阴影有绘制空间。
- 内层承载白底、紫边、圆角、阴影。
- 小叉位于内层顶部行最右侧。


────────────────────────────────────────
四、视觉规范
────────────────────────────────────────

内层容器样式（建议用 QSS 设置）：

- 背景色：白色           background-color: #FFFFFF
- 边框：2px 实线紫色      border: 2px solid #8A2BE2
- 圆角：12px             border-radius: 12px

色值与尺寸均建议集中定义，便于后续调整。
若后续需要渐变边、异形边，再改为重写 paintEvent 自绘；
本次使用 QSS 即可，无需自绘。

阴影：
- 使用 QGraphicsDropShadowEffect 给内层容器加阴影。
- 外层必须留出 margin，否则阴影会被裁掉。
- 阴影参数建议：模糊半径 20~30，偏移 0~4，颜色为半透明黑。


────────────────────────────────────────
五、右上角小叉
────────────────────────────────────────

- 控件类型：QPushButton 或 QLabel 均可，推荐 QPushButton。
- 内容：字符「×」或矢量图标。
- 位置：内层顶部行最右侧，用布局固定，避免被其它控件遮挡。
- 交互：
  - 悬停时颜色变化（建议紫边同色系）。
  - 点击调用 self.close()。
- 无障碍：设置合适的对象名，便于测试定位。


────────────────────────────────────────
六、无边框后必须补的功能
────────────────────────────────────────

1. 窗口拖动
   - 无边框后无法再拖标题栏。
   - 在顶部/空白区实现拖动：
     mousePressEvent 记录起点 → mouseMoveEvent 移动窗口。
   - 拖动逻辑必须限定在非输入框、非按钮区域，
     否则在输入框内选文字时窗口会乱跑。
   - 建议定义一个可拖动区域（如顶部行），只在该区域内响应拖动。

2. 阴影
   - 见第四节，必须配合外层 margin。

3. 关闭逻辑
   - 小叉点击后仍走原有 close()。
   - closeEvent 清空记忆并 emit closed，保持不变。
   - WA_DeleteOnClose 保留。


────────────────────────────────────────
七、必须保留的现有行为
────────────────────────────────────────

不得改变对外接口与信号：

- 只读日志 + 输入框 + 发送（Enter / 按钮）
- _history 仅存本次会话
- 关闭方式：小叉、Esc、点外部（WindowDeactivate）均关闭
- closeEvent 清空记忆并 emit closed
- WA_DeleteOnClose 销毁实例
- 桌宠正上方落位（放不下落下方、按外框钳制屏内）
- 重复唤起只 raise


────────────────────────────────────────
八、容易踩的坑（请自查）
────────────────────────────────────────

1. 圆角出现黑角
   → 忘记 WA_TranslucentBackground，或内层未设 border-radius。

2. 紫边被裁
   → 外层 margin 太小，边框贴边。

3. 小叉点不到
   → 被日志区或布局盖住，检查层级与 z-order。

4. 拖动与输入冲突
   → 拖动绑定到了整个窗口，需限定拖动区域。

5. Esc / 点外部失效
   → 误加了 WindowDoesNotAcceptFocus，导致点外部不触发失焦。

6. 高 DPI 下边框发虚
   → 边框宽度使用整数，避免 1.5px 这类非整值。

7. 阴影不明显或被裁
   → 外层 margin 不足，或阴影效果加在了外层而非内层。

8. 流式输出时窗口尺寸跳动
   → 若气泡/日志区随内容增高，注意刷新频率与最大高度限制，
     本次改造不改变该逻辑，但需确认未被样式改动破坏。


────────────────────────────────────────
九、验收标准
────────────────────────────────────────

1. 对话框为白底、紫边、圆角、带阴影，无任何系统原生装饰。
2. 右上角有小叉，点击可关闭。
3. 小叉、Esc、点外部三种方式关闭后：
   - 清空记忆
   - 发出 closed 信号
   - 窗口销毁
4. 原有落位、raise、输入、发送、只读日志行为不变。
5. 在输入框内选文字时窗口不移动。
6. 新增一条离屏测试：
   - 验证小叉点击后 closed 信号发出
   - 验证记忆被清空
