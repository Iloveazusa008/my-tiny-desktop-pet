# AI 桌面宠物 · 纲领性文件

> 本文件用于指导 Agent 实现项目。只写结论与约束，不写实现细节。凡是本文件未提及的，Agent 可自行决策，但不得违背已列约束。

---

## 一、项目定位

一个运行于 Windows 的桌面宠物程序。桌宠以 GIF 动画呈现，可在桌面上随机走动、被拖动、被点击，并通过右键菜单唤起对话气泡，调用 OpenAI 兼容接口进行人格化流式对话。

- 平台：仅 Windows
- 语言：Python
- 不做：语音、3D、Live2D、移动端、多角色、多显示器适配、开机自启、自动更新

---

## 二、角色与人格规范

- 人格完全由用户自定义的 system prompt 决定，程序不预设任何人格
- system prompt 存放于独立配置文件，用户直接编辑
- 程序不得在 prompt 之外附加任何人格倾向
- 程序不得向用户暴露「AI 身份」相关提示（除非用户 prompt 自身要求）

---

## 三、行为状态机

桌宠至少包含以下状态，并定义迁移：

| 状态 | 触发 | 表现 |
|---|---|---|
| 待机 | 默认 | 循环播放 idle |
| 走动 | 随机发起 | 循环播放 walk，窗口位移 |
| 被点击 | 左键单击 | 播放一次 click，随后回到待机 |
| 说话 | 对话进行中 | 循环播放 talk |
| 被拖动 | 按住拖拽 | 循环播放 drag（可复用 click） |
| 调用失败 | API 异常 | 播放一次 error，随后回到待机 |

约束：
- 走动随机发起，非用户指令触发
- 走动范围：整个桌面，不考虑多显示器，不强制避开任务栏
- 走动时碰到屏幕边缘反向
- 对话期间**停止走动**
- 左键单击仅播放 click，不打开对话框
- 右键打开菜单，菜单内含「开始对话」入口

---

## 四、交互规范

**右键菜单**
- 使用原生 Qt 菜单
- 菜单承担全部控制入口，不单独做系统托盘
- 菜单项至少包含：开始对话、暂停/恢复走动、回到屏幕中央、打开配置文件、退出
- 不提供「切换模型」菜单项，模型信息写在配置文件

**对话框**
- 由右键菜单唤起
- 对话期间桌宠停止走动
- 支持多轮对话，上下文仅在本次会话内保留
- 关闭对话框即清空全部会话记忆
- 关闭方式（X、Esc、点外部）均视为关闭并清空
- 流式输出中关闭对话框，立即中断请求
- 输出中禁用用户输入，输出完成后恢复

**气泡**
- 纯代码绘制，不使用任何图片素材
- 用 QPainter 绘制圆角矩形 + 描边 + 指向桌宠的小尾巴
- 宽度有最小/最大值，文字自动换行
- 高度随内容自适应
- 默认位于桌宠上方，空间不足时翻到下方
- 流式输出时逐字追加，刷新合并到固定频率，不做每 token 重绘
- 增长不得超出屏幕边界，超出则限制最大高度
- 禁止引入气泡图片、九宫格、QSS border-image、第三方 UI 库
- 样式参数（圆角、边框、填充、透明度、字体、字号、最大宽度）写入配置文件

---

## 五、技术约束

**GUI**
- PySide6 为唯一 GUI 依赖
- 主窗口：无边框、透明背景、始终置顶、不在任务栏显示

**动画**
- GIF 播放
- 走动方向由两套 GIF 分别承担（向左、向右），不做镜像翻转
- 动画文件路径映射写入配置文件

**AI 接入**
- 使用 OpenAI SDK
- 通过配置文件的 base_url 切换云端/本地，代码零改动
- 支持流式输出
- API 调用失败：关闭对话框，播放 error GIF
- 不预设模型名，由用户配置

**配置**
- 分两个文件：行为与模型连接配置、人格 prompt
- 不支持热重载，修改后重启生效

**性能**
- 走动位移使用定时器驱动，频率适中
- 后台常驻，不主动占用高 CPU

---

## 六、配置规范

配置文件需覆盖：

- API：base_url、api_key、model
- 人格：独立 prompt 文件路径
- 行为：走动速度、走动发起频率、是否启用走动
- 动画：各状态对应 GIF 路径
- 气泡：圆角、边框色、填充色、透明度、字体、字号、最大宽度
- 启动位置：默认右下角

| 用途 | 必需 |
|---|---|
| idle | 是 |
| walk 向左 | 是 |
| walk 向右 | 是 |
| click | 是 |

## 八、交付边界

**必须交付**
- 可运行的 Python 程序
- 配置文件与人格 prompt 文件
- 资源目录结构
- 启动说明

**明确不做**
- 语音输入输出
- 3D / Live2D
- 移动端
- 自动更新
- 多角色
- 多显示器适配
- 开机自启
- 快捷键
- 托盘图标
- 配置热重载
- 模型切换菜单

---

## 九、验收标准

1. 启动后桌宠出现在屏幕右下角，透明置顶，无边框，不在任务栏显示
2. 能自动随机走动，碰边反向，左右 GIF 正确切换
3. 能拖动换位，拖动时有对应表现
4. 左键单击播放 click
5. 右键弹出原生菜单，菜单项完整
6. 菜单可唤起对话框，对话期间停止走动
7. 对话支持多轮，带上下文
8. 流式输出呈现于自绘气泡，气泡随文字增长
9. 关闭对话框清空记忆
10. 输出中关闭对话框，请求立即中断
11. API 失败时关闭对话框并播放 error
12. 云端/本地通过配置文件切换，代码不变
